# SB-20261029-003 動画閲覧プロジェクトの編集・削除権限

## 目的と承認範囲

一般部員・保護者に「動画追加」または「タグ編集」が許可されていても、動画閲覧のプロジェクト編集画面を開けなかった。管理シート「改訂履歴」112行の仕様と、2026/10/29の実装指示に基づき、閲覧用プロジェクトの管理権限を拡張した。

開始時は `master`、未commit変更・未追跡ファイルなし。専用ブランチは `codex/sb-20261029-003-viewing-project-permissions`。

当初はキャプテンを対象外としていたが、2026/10/29の追加指示により、キャプテンにも個別許可なしで閲覧用プロジェクトの編集・削除を許可した。この追加指示を管理シートの当初仕様より優先して反映している。

## 実装した仕様

| 役割 | 動画追加 | タグ編集 | 閲覧用プロジェクトの編集・削除 |
| --- | --- | --- | --- |
| owner / admin / staff | 任意 | 任意 | 可能（従来どおり） |
| captain | 任意 | 任意 | 可能（追加指示により対象へ追加） |
| member / guardian | OFF | OFF | 不可 |
| member / guardian | ON | OFF | 可能 |
| member / guardian | OFF | ON | 可能 |
| member / guardian | ON | ON | 可能 |
| 不明な役割 | 任意 | 任意 | 不可（従来どおり） |

- 対象は、閲覧用プロジェクトの名称変更・構成動画変更・削除。作成者本人だけへの制限は加えていない。
- `canManageViewingProject` を共通化し、編集ボタンと、開く・保存する・削除する操作で利用する。
- 削除確認を開いた後に権限取消・チーム切替・画面離脱・アンマウントがあれば、確定しても書き込まない。
- 保存・削除の失敗時は編集内容を維持し、再試行できる。
- 削除は既存の `deleteHighlightProject` による論理削除。元動画やタグは削除しない。
- 元動画の管理権限、新規作成、登録ダイアログからの「既存に追加」の権限は維持する。
- 新規API・Cloud Functions・定期処理・データ移行は追加しない。保存先・データ形式も維持する。
