## 実装した動作

1. 設定の「所属チーム情報・入部用コード」に「部員を招待（LINE・メールなど）」「招待文をコピー」を追加。現行の監督・管理者・スタッフの表示権限を維持する。共有文にはチーム名、取得リンク、参加リンク、コード、2段階の手順、初回登録と確認メールの案内を含める。送信先選択・送信は利用者が行う。
2. 正式な招待URLは `https://sharprise.jp/smartbukatsu/invite/?code=<6文字コード>`。取得リンクには同じURLへ `&step=download` を付ける。アプリ未取得ならWebの案内を表示し、取得済みならアプリで参加へ進める。リンクがアプリ内ブラウザ等で開かれる場合は、案内ページの「アプリを開いて参加する」を利用する。
3. 新規利用者はコード入力済みの部員登録へ、既存利用者はコード入力済みのチーム参加へ進む。招待経由のチーム選択では、参加操作を先に見せるため所属一覧と新規チーム作成を一時的に隠す。取り消すと通常画面へ戻る。
4. 招待情報を端末に保存し、ログインや再起動をまたいで保持する。参加・部員登録の成功または本人の取り消しで削除。参加に失敗した場合は保持する。後から届いた別の招待を、古い起動リンク・Google Play情報・処理完了通知で上書き／消去しない。
5. AndroidのストアボタンにGoogle Play Install Referrerを付け、既存の`expo-application`で初回起動時に取得する。過去の取得情報を一度処理したことも端末に保存し、参加完了後に復活させない。Google Playを経由しない取得・取得情報が届かない環境・サービスエラーでは、再タップ／本文のコードを利用する。
6. iPhoneは取得後に元の招待文へ戻って参加リンクを再タップする方式。案内ページのアプリ起動ボタンも利用できる。インストールをまたぐ完全自動の引き継ぎ、有料外部サービス、自動のクリップボード読み取りは導入していない。
7. リンク受信だけで登録・チーム参加は実行しない。名前・メール・パスワード、年齢・利用条件への同意、確認メールの既存フローを維持。所属済みチームへの招待は所属数上限時にも既存の所属確認を経て開ける。
8. チーム名とコードが同じチームのものだと確認できるまで共有を無効化する。設定画面に遅れて届いた前チームの情報で、現在の招待文を作らない。
