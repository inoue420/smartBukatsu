## 確定仕様

| 項目 | 動作 |
| --- | --- |
| 設定 | チーム単位。オーナー・管理者だけが変更可能 |
| 初期状態 | OFF。設定未登録の既存チームもOFF |
| OFF | 新規コメント送信、通報時の証拠コピー、通報後の証拠追跡を停止 |
| OFF中の通報 | 既存コメントから受付可能。理由、任意記入の詳細、対象ID等の案件情報を保存し、コメント本文・会話の自動コピーは保存しない |
| ON | コメント送信と既存の通報用保存を有効化。証拠保存・運営の確認・必要な範囲での情報開示について画面に表示 |
| 再度ON | 以後の通報・関連変更から再開。停止処理のまとめ実行なし。以前の遅延イベントは保存・返信通知を抑止 |
| 既存データ | 既存コメントは閲覧・通報可能。保存済み証拠は現在の保持期限とlegalHoldに従って保持 |
| 保存範囲 | 現在の日報コメント通報用保存だけ。全会話の常時バックアップは追加しない |

ON後の新しい通報・関連変更では、現在の方式で既存の会話部分を証拠へコピーする。既存コメントを削除・移動したり、ON/OFF期間ごとに会話本文を分割したりしない。掲示板投稿・返信の通報、日報本体の作成・編集・確認済み・スター等は維持する。

## 負荷への影響

OFF中は新規コメント更新、更新配信、送信前検査、返信通知・未読件数・プッシュ送信、通報証拠コピーが発生しなくなる。通常表示では既存チーム文書の購読を利用し、設定専用購読を追加しない。日報自体の取得・保存は維持する。既存の読み込み最適化の再準備も設定切替だけでは発生しない。
厳密な切替制御のため、設定変更時・通報受付時・追跡処理時・ON中の通知トランザクションには設定確認の読み取りが発生する。OFFでも通常の日報編集によるFunction起動は残り、指紋が変わる変更ではチーム設定1文書を確認する。ON中の追跡では案件検索に加え、各対象案件の保存トランザクションでチーム設定と案件を読む。従来よりON中の読取が増える部分がある。
全体の読み込み・書き込み削減率、実行時間、費用は未実測。コメント件数、購読端末数、OFF利用率、通報数、再接続等によって変わる。
